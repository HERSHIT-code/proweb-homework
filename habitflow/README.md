# HabitFlow — full-stack трекер привычек

Домашнее задание курса AI-конструирование: **PRD → SPEC → рабочее приложение с локальной БД**.

## Документы
- [`PRD.md`](PRD.md) — продукт: проблема, пользователь, сценарии, требования, метрики.
- [`SPEC.md`](SPEC.md) — техника: стек, архитектура, модель данных, REST API, алгоритмы, критерии приёмки.

## Стек
Python 3.11 (только стандартная библиотека: `http.server`, `sqlite3`, `urllib`) + HTML/CSS/vanilla JS.
Никаких `pip install` — запускается сразу.

## Запуск
```bash
cd habitflow
python app.py
# → http://127.0.0.1:8000
```
База создаётся автоматически в `habits.db` рядом с `app.py`.

## API
| Метод | Путь | Что делает |
|---|---|---|
| GET | `/api/habits` | список привычек со серией, лучшей серией, % за 30 дней, последними 14 днями |
| POST | `/api/habits` | создать: `{"name":"Чтение","color":"#4ade80"}` |
| DELETE | `/api/habits/{id}` | удалить привычку и её отметки |
| POST | `/api/habits/{id}/toggle` | отметить/снять отметку за сегодня (или `{"day":"2026-10-21"}`) |
| GET | `/api/stats` | сводка: привычек, сделано сегодня, лучшая серия, средний % |
| GET | `/api/health` | статус и активный бэкенд (`sqlite` / `turso`) |

Пример:
```bash
curl -X POST http://127.0.0.1:8000/api/habits -H "Content-Type: application/json" -d "{\"name\":\"Чтение\"}"
curl -X POST http://127.0.0.1:8000/api/habits/1/toggle
curl http://127.0.0.1:8000/api/habits
```

## Структура
```
habitflow/
├─ PRD.md
├─ SPEC.md
├─ app.py            # HTTP-сервер и маршруты API
├─ db.py             # SQL-слой: SQLite локально / Turso в облаке
├─ static/index.html # интерфейс
└─ habits.db         # создаётся при первом запуске
```

## Что проверено
- Создание, отметка, снятие отметки, удаление привычки.
- Серия и лучшая серия считаются корректно (пересчёт из таблицы `checkins`).
- Данные сохраняются между перезапусками сервера.
- Вёрстка адаптивна от 360 px.
