# KofeLab — одностраничный сайт (HW: «Генерация сайта через Lovable»)

Лендинг вымышленной кофейни, собранный по образцу задания: герой-блок, блок услуг с ценами,
форма заявки, адаптив под телефон.

## Что внутри
- **Hero**: заголовок, описание, две CTA-кнопки, три показателя, иллюстрация чашки (inline SVG).
- **Услуги и цены**: три карточки (напитки / завтраки / подписка) с ценниками в сумах.
- **Почему мы + форма заявки**: поля «Имя», «Телефон», «Что нужно», «Комментарий»;
  валидация и сохранение заявок в `localStorage`.
- **Адаптив**: брейкпоинт 900px — карточки в колонку, навигация сворачивается, герой перестраивается.
- Тёмная тема, sticky-хедер с blur, плавный скролл по якорям.

## Запуск
Открыть `index.html` в браузере или:
```bash
python -m http.server 8080   # → http://localhost:8080
```
