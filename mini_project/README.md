# Focus Timer — мини-проект (HW: «Свой мини-проект через браузерную модель»)

Одностраничное приложение без сборки и зависимостей: помодоро-таймер + список задач на сессию.

## Что умеет
- Три режима: работа 25 мин, короткий перерыв 5 мин, длинный 15 мин.
- Круговой прогресс, пауза/продолжение, сброс, звуковой сигнал по завершении.
- Счётчик завершённых сессий и задачи с чекбоксами — всё сохраняется в `localStorage`.
- Горячая клавиша `Space` — старт/пауза, адаптив под телефон.

## Как запустить
1. Скачать и распаковать архив.
2. Открыть `index.html` двойным кликом в любом браузере (Chrome / Edge / Safari).
   Или: `python -m http.server 8080` в папке проекта → http://localhost:8080

## Инструменты
Vanilla JS (ES6+), HTML5, CSS3 (SVG-прогресс, CSS-переменные), Web Audio API, localStorage.
Код получен и доработан в диалоге с браузерной ИИ-моделью.
